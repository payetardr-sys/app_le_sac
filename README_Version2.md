# SAC Android App

Application de suivi de consommation et de réduction des risques (RdR).

## Structure

- Kotlin + Jetpack Compose
- Navigation par menu en bas
- Base de données locale (Room)
- Logo : `app/src/main/res/drawable/logo_rdr.png`
- Icône : `app/src/main/res/mipmap/ic_launcher.png`

## Installation

1. Ouvre Android Studio, choisis "Importer un projet existant" ou crée un nouveau projet vide.
2. Copie les fichiers fournis ici (respecte bien les dossiers indiqués).
3. Place l’image du logo dans `app/src/main/res/drawable/logo_rdr.png` (image 1).
4. Place l’icône dans `app/src/main/res/mipmap/ic_launcher.png` (image 2).
5. Compile et lance sur ton téléphone ou émulateur.

## Personnalisation

- Modifie le logo ou l’icône en remplaçant les fichiers images.
- Les couleurs pastel sont définies dans `colors.xml` et `Theme.kt`.
