# Guide Utilisateur - Daylio SAC

## Bienvenue dans Daylio SAC

Daylio SAC est votre compagnon pour un suivi personnel et confidentiel de vos consommations. Cette application vous aide à mieux comprendre vos habitudes et à prendre des décisions éclairées.

## Premier lancement

### Configuration initiale

1. **Définir votre code PIN**
   - Au premier lancement, l'application vous demande de définir un code PIN à 4-6 chiffres
   - Ce code protège l'accès à vos données
   - Choisissez un code que vous n'oublierez pas
   - Ne le partagez avec personne

2. **Paramètres de confidentialité**
   - Activez/désactivez le verrouillage automatique
   - Configurez le délai avant verrouillage
   - Activez/désactivez les actualités RSS

## Fonctionnalités principales

### 1. Enregistrer une consommation

#### Étapes :
1. Appuyez sur le bouton **"+"** (flottant en bas à droite)
2. Sélectionnez ou créez un produit
3. Indiquez la quantité et l'unité
4. Sélectionnez votre humeur (optionnel)
5. Ajoutez une note (optionnel)
6. Validez

#### Conseils :
- Soyez honnête avec vous-même
- Notez rapidement après la consommation
- Utilisez les notes pour le contexte
- L'humeur aide à identifier les patterns

### 2. Consulter l'historique

#### Accès :
- Écran principal : liste chronologique des consommations
- Filtre par période, produit, ou humeur
- Recherche dans les notes

#### Actions disponibles :
- **Modifier** : Toucher une entrée pour l'éditer
- **Supprimer** : Glisser vers la gauche
- **Détails** : Toucher pour voir les détails complets

### 3. Analyser les statistiques

#### Types d'analyses :

**Progression**
- Évolution des consommations dans le temps
- Identification des tendances
- Comparaison entre périodes

**Corrélations**
- Relation entre consommation et humeur
- Identification des contextes à risque
- Patterns temporels

**Abstinence**
- Suivi des périodes sans consommation
- Objectifs d'abstinence
- Compteur de jours consécutifs

**Graphiques disponibles**
- Graphiques linéaires (évolution)
- Graphiques en barres (comparaison)
- Graphiques circulaires (répartition)
- Calendrier de consommation

#### Comment interpréter :
- Les courbes descendantes = amélioration
- Les pics = moments à analyser
- Les patterns réguliers = habitudes à identifier

### 4. Guides de réduction des risques

#### Navigation :
1. Menu principal → **Guides**
2. Parcourir par catégorie
3. Rechercher un sujet spécifique

#### Contenu :
- Principes généraux de réduction des risques
- Gestion des urgences
- Conseils spécifiques par produit
- Ressources et contacts utiles

#### Utilisation :
- Lisez avant une nouvelle expérience
- Référez-vous en cas de doute
- Partagez avec vos proches (optionnel)

### 5. Actualités RSS

#### Activation :
1. Menu → **Paramètres**
2. Activez **"Actualités RSS"**
3. Sélectionnez les flux à suivre

#### Utilisation :
- Consultez les dernières actualités
- Marquez comme lu
- Ouvrez les articles dans le navigateur

#### Désactivation :
- Pour un usage 100% hors ligne
- Désactivez dans les paramètres

### 6. Export des données

#### Formats disponibles :

**PDF**
- Rapport complet et formaté
- Inclut les graphiques
- Idéal pour partage avec professionnel
- Protégé par mot de passe (optionnel)

**CSV**
- Données tabulaires
- Import dans Excel/Calc
- Analyse personnalisée
- Léger et universel

**JSON**
- Données brutes complètes
- Backup de sécurité
- Migration vers autre app
- Format technique

#### Procédure :
1. Menu → **Export**
2. Choisissez le format
3. Sélectionnez la période
4. Options d'export
5. Confirmez
6. Partagez ou sauvegardez

## Sécurité et confidentialité

### Protection des données

**Stockage local uniquement**
- Aucune synchronisation cloud
- Données sur votre appareil uniquement
- Contrôle total de vos informations

**Chiffrement**
- Base de données chiffrée AES-256
- Clé dérivée de votre PIN
- Protection contre accès non autorisé

**Code PIN**
- Requis à chaque ouverture
- Verrouillage automatique
- 3 tentatives maximum

### Que faire en cas de problème ?

**PIN oublié**
⚠️ Impossible de récupérer les données sans PIN
- Aucune porte dérobée (par conception)
- Réinstallation = perte des données
- **Solution** : Conservez des exports réguliers

**Appareil perdu/volé**
- Les données sont chiffrées
- Le voleur ne peut pas y accéder sans PIN
- 3 tentatives échouées = verrouillage long

**Désinstallation**
⚠️ Toutes les données sont supprimées
- Exportez avant de désinstaller
- Conservez les exports en lieu sûr

## Astuces et bonnes pratiques

### Pour un suivi efficace

1. **Soyez régulier**
   - Enregistrez rapidement après consommation
   - Ne comptez pas sur votre mémoire
   - Faites-en une habitude

2. **Soyez honnête**
   - Personne d'autre ne voit vos données
   - L'auto-tromperie n'aide pas
   - C'est pour vous, pas pour les autres

3. **Utilisez les notes**
   - Contexte de la consommation
   - Déclencheurs identifiés
   - Ressentis et observations

4. **Consultez les stats**
   - Au moins une fois par semaine
   - Identifiez les patterns
   - Ajustez vos comportements

5. **Fixez-vous des objectifs**
   - Réalistes et progressifs
   - Mesurables dans le temps
   - Célébrez les réussites

### Pour la sécurité

1. **Exportez régulièrement**
   - Backup hebdomadaire recommandé
   - Stockez en lieu sûr
   - Testez la restauration

2. **Protégez votre PIN**
   - Ne le partagez jamais
   - Différent des autres codes
   - Mémorisable mais pas évident

3. **Verrouillez systématiquement**
   - Activez le verrouillage auto
   - Verrouillez manuellement si besoin
   - Ne laissez pas l'app ouverte

## FAQ

### L'application est-elle vraiment confidentielle ?
Oui, à 100%. Aucune donnée ne quitte votre appareil (sauf actualités RSS optionnelles). Pas de compte, pas de serveur, pas de tracking.

### Puis-je utiliser l'app sur plusieurs appareils ?
Non, par conception. Chaque installation est indépendante. Vous pouvez exporter/importer manuellement.

### Les actualités RSS violent-elles ma vie privée ?
Non. Les flux RSS sont anonymes. Votre appareil télécharge simplement des articles publics. Aucune donnée personnelle n'est transmise.

### Puis-je partager mes données avec un professionnel ?
Oui, via l'export PDF. Vous contrôlez ce que vous partagez et avec qui.

### L'application remplace-t-elle un suivi médical ?
Non. C'est un outil d'auto-observation. Consultez un professionnel de santé pour un accompagnement médical.

### Que faire si j'identifie un problème de dépendance ?
Contactez :
- Votre médecin traitant
- Un CSAPA (Centre de Soins en Addictologie)
- Drogues Info Service : 0 800 23 13 13

### L'application juge-t-elle mes consommations ?
Non. Elle enregistre objectivement. Aucun jugement, aucune alerte moralisatrice. C'est un outil d'aide à la décision.
